# 🎧 VC JOIN LEAVE TRACKER

Telegram Voice Chat **JOIN / LEAVE Tracker** powered by Pyrogram + MongoDB.

Track users joining and leaving Voice Chats with time and duration logs.

---

## ✨ Features

- 🟢 VC Join Detection
- 🔴 VC Leave Detection
- 🕐 Join Time
- 🕐 Leave Time
- ⏱️ Stay Duration
- 🆔 User ID
- 👤 Username & Name
- 📢 Logs Channel
- 💾 MongoDB Storage
- ☁️ Heroku Support
